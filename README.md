# Retail Sales Data Management Project

## 📌 Project Overview
This repository contains a cleaned retail transaction dataset. The dataset includes detailed information on customer demographics, product categories, purchasing behaviors, payment methods, and feedback ratings. 

This project was built to demonstrate data cleaning, version control, and preparation for exploratory data analysis (EDA).

## 📂 Dataset Features
The dataset (`retail_clean.csv`) includes the following key attributes:
* **Customer Info:** ID, Name, Age, Gender, Income Level, Segment (New, Regular, Premium).
* **Transaction Details:** Transaction ID, Date, Time, Total Amount, Total Purchases.
* **Product Info:** Category (Clothing, Electronics, Books, etc.), Brand, Product Type.
* **Order Details:** Shipping Method, Payment Method (Credit Card, PayPal, Cash), Order Status.
* **Customer Feedback:** Ratings (1-5) and Feedback category.
